# Standard Model Fields（標準模型の相互作用を 3 次元で見る）

量子場の状態から計算した量を、ブラウザの中で 3 次元に描くビューアです。2 つのページがあります。

- `index.html`（描写）: 説明のない、見るためのページ。操作がなければ各トピックを「分散 → 相関」の順に 1 回ずつ再生して次へ進みます。
- `theory.html`（理論）: 何を描いているか・仮定・近似・脚色を、トピックごとに数式で書いたページ。
- `guide.html`（操作方法）: 画面の部品と、視点・時間の操作（図）。
- 言語: 日本語・英語・ドイツ語（描写のページの右上の ja / en / de、説明のページの上の帯）。選んだ言語は 3 つのページで共通です
  （英語・ドイツ語の説明のページは `theory.en.html`, `theory.de.html`, `guide.en.html`, `guide.de.html`）。

## 使い方

1. 配布の zip（GitHub の Releases の `standard-model-fields-<version>.zip`。計算したデータ `data/` を含む）を展開し、`index.html` をブラウザ（Chrome / Edge / Firefox / Safari の新しい版、WebGL2 が必要）で開きます。サーバーは要りません。
2. 左下でトピックを、右下で粒子（場）の表示と「分散 / 相関」を切り替えます。右上の「音」で BGM、「理論」で説明のページへ。
3. 操作をやめて 45 秒たつと、自動の巡回に戻ります。

| 操作 | |
|---|---|
| ドラッグ | 回転 |
| 右ドラッグ / Shift + ドラッグ | 平行移動 |
| ホイール | 拡大・縮小（箱の中にも入れる） |
| ダブルクリック | 視点を戻す |
| 下の縁の細い線 | 時間を動かす |
| Space | 一時停止 |
| ← → | 1 コマ戻す・進める |

- 分散: ボゾンは場の分散の増加（真空との差）、フェルミオンは電荷（数）の密度
- 相関: 2 点の相関から 1 個の粒子の位置をある点と仮定したときの分布。その点は位置を仮定した粒子の色の小さな分布で示します（粒子とともに動く）

## トピック

| | 内容 |
|---|---|
| i. 電子と電子 | 同じスピンの 2 電子。交換される光子、クーロン場、横の光子（量子のモード）と放射 |
| ii. コンプトン散乱 | 止まった電子に光子が当たる（最低次、クライン–仁科）。散乱した光子の殻と反跳した電子。光子の位置を仮定した向きで電子の向きと速さが決まる |
| iii. ベータ崩壊 | 動く中性子から電子と反ニュートリノ（ドップラーで前に寄る）。中性子 → 陽子、崩壊する前の W の衣。角相関 1 + v cosθ |
| iv. ニュートリノ振動 | π⁺ → μ⁺ν<sub>μ</sub>。フレーバー（μ, τ）と質量（1, 2）の密度 |
| v. 色の閉じ込め | 色 1 重項のクォークと反クォーク。色の誘電体の模型の解として間に伸びる色の束（ひも）が 2 つを引き戻す |
| vi. π 中間子の交換 | 陽子と中性子。電荷の入れ替わり |
| vii. 真空偏極 | 広がる電子のまわりで真空が帯びる電荷（1 ループ、実際の α）。電子の位置と仮定した点のまわりにはコンプトン波長の雲 |

## 注意

- 単位は ħ = c = 1。結合の強さ・質量・距離などの定数は、見やすさのために脚色しています（一覧は `theory.html`）。
- 計算の箱は描かず、箱の縁へ向けて濃さをなだらかに 0 にしています（表示だけ）。
